# ADR-0005: PWA and hosting

- **Status:** Accepted, 2026-11-02.

| Decision                                                                                                                                                                                         | Why                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **The service worker precaches the app shell only** (`vite-plugin-pwa`, generateSW). Documents are never in the service-worker cache.                                                            | Documents belong to the library, which the reader controls.                                                                                                            |
| **Updates wait for the reader** (`registerType: "prompt"`): a toast offers Reload.                                                                                                               | A new version never replaces the page mid-reading.                                                                                                                     |
| **The manifest declares `file_handlers` for `.flexova`** and `launch_handler: focus-existing`.                                                                                                   | Installed FlexPad opens `.flexova` files from the desktop (Chromium).                                                                                                  |
| **Installability is checked with Chromium's `Page.getInstallabilityErrors`** in the e2e suite.                                                                                                   | Lighthouse 12+ removed its PWA category, so "Lighthouse installable" can no longer be measured. Lighthouse still gates accessibility (≥ 95) and best practices (≥ 90). |
| **Hosting: Cloudflare Pages**, connected by the owner in the Cloudflare dashboard (no deploy secrets in the repo). Every branch gets a preview URL. `public/_headers` sets the security headers. | Free for private repositories, supports custom headers, HTTPS by default (required for service workers).                                                               |
