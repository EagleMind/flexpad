# ADR-0008: The editor (M5)

- **Status:** Accepted, 2026-11-02.
- **Changes** the build plan's "Tiptap" and "jSquash WASM" choices (see rows 1 and 5).

| #   | Decision                                                                                                                                                                                                                                                                                                                                                                                                                               | Why                                                                                                                                                              |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **ProseMirror directly, without Tiptap.** The schema is generated at runtime from the profile that `@flexova/core` exports. Each element's attributes come from the profile, and every profile element flagged as a mark becomes a mark. A test fails if the profile gains an element the editor doesn't handle.                                                                                                                       | Generating a schema from data is natural in ProseMirror. Tiptap's per-extension node definitions would have meant writing the profile out by hand a second time. |
| 2   | **Saving normalizes what the schema can't express**, then core's `write()` validates the result. That covers: required and unique ids; links whose target is gone (unlinked with a warning, keeping their own id as a `<span>`); at most one table, code block, quote, audio or formula per figure (extras follow the figure); definition lists missing terms or definitions; rows left empty by merged cells; XML-illegal characters. | Valid by construction. A randomized test applies 200 sequences of 30 edits (2,000 were checked locally) and every save is a valid package.                       |
| 3   | **Loading parses each chapter with core's strict XML parser** into an inert DOM that is never attached to the page, then through the schema's parse rules. MathML, `<picture>` and audio are kept as atoms that round-trip unchanged. The loader's markers use a per-session random attribute name, so pasted HTML can't forge them, and MathML is re-checked against the profile on save.                                             | The 13 conformance packages and both samples round-trip with canonically identical bodies, and saving twice gives identical bytes.                               |
| 4   | **Word import uses mammoth, in the browser, loaded only when needed.** Its HTML goes through the same schema parse rules, so only profile content survives. Paragraph styles named Note, Tip, Important, Warning or Caution become callouts. Markdown import uses `@flexova/import`.                                                                                                                                                   | Works offline, keeps nothing unsafe, and adds no weight to reading.                                                                                              |
| 5   | **Images are re-encoded in a canvas:** WebP where the browser can encode it, otherwise JPEG for photos and PNG for graphics, at most 1,600 px on the long side. No WebAssembly encoder.                                                                                                                                                                                                                                                | A WASM encoder needs `'wasm-unsafe-eval'` in the CSP (ADR-0003). Canvas re-encoding also strips anything but pixels, including metadata and scripts in SVG.      |
| 6   | **Alt text is required** when inserting an image, unless the author marks it decorative.                                                                                                                                                                                                                                                                                                                                               | The profile requires `alt`. An empty value has to be a deliberate choice.                                                                                        |
| 7   | **Theme colors are checked live** against the same contrast rule validators use (`CONTRAST_RULE` from core). Apply stays disabled while any text color is below 4.5:1.                                                                                                                                                                                                                                                                 | The author sees the problem while choosing colors, not as a failed save.                                                                                         |
| 8   | **Saving uses the File System Access API where available**, reusing the handle for later saves, and a download elsewhere. **Unsaved work is kept as a draft** in IndexedDB 1.5 s after each change, and offered back when the document is opened again.                                                                                                                                                                                | Works in every browser, and a closed tab or crash loses nothing.                                                                                                 |
| 9   | **A new document is titled by its first heading** until the author sets a title.                                                                                                                                                                                                                                                                                                                                                       | What people expect, with no extra step.                                                                                                                          |
| 10  | **The editor and importers are separate, lazily loaded chunks.**                                                                                                                                                                                                                                                                                                                                                                       | Reading stays as light as in M4.                                                                                                                                 |
