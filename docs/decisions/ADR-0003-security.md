# ADR-0003: Security

- **Status:** Accepted, 2026-11-02.

| Decision                                                                                                                                                                                                                                                                                                                                           | Why                                                                                                                                   |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Documents are rendered only by `<flexova-viewer>`**, which rebuilds markup from the profile's allowlist in a Shadow DOM. FlexPad never injects markup (ESLint bans `dangerouslySetInnerHTML` and `innerHTML`).                                                                                                                                   | One audited sanitizer (flexova ADR-0007).                                                                                             |
| **Invalid packages still open,** through the same sanitizer, with a banner listing their problems.                                                                                                                                                                                                                                                 | Readers shouldn't be locked out of slightly broken files from other tools; safety comes from the viewer, not from refusing.           |
| **CSP** (in `public/_headers`): `default-src 'self'`, `script-src 'self'`, `style-src 'self' 'unsafe-inline'`, `img-src`/`media-src 'self' blob: data:`, `connect-src 'self'`, `object-src 'none'`, `base-uri 'none'`, `frame-ancestors 'none'`, `form-action 'none'`; plus `nosniff`, `no-referrer`, COOP and a restrictive `Permissions-Policy`. | `'unsafe-inline'` is for styles only: the viewer's per-document theme is a `<style>` in its shadow root. No inline script is allowed. |
| **`?src=` accepts same-origin URLs only.**                                                                                                                                                                                                                                                                                                         | FlexPad must not be usable to fetch documents from other sites on a user's behalf.                                                    |
| **Signatures are verified only against keys the reader imported.** The document itself is never trusted to name its key.                                                                                                                                                                                                                           | Flexova spec section 11.                                                                                                              |
