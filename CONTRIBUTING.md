# Contributing to FlexPad

Thanks for your interest. FlexPad is licensed under the [AGPL-3.0](LICENSE).

**We can't accept outside pull requests yet.** The project owner intends to offer FlexPad under other licenses as well (dual licensing), which requires a contributor license agreement before outside code can be merged. Until that exists, please:

- report bugs and suggest ideas in [GitHub issues](https://github.com/EagleMind/flexpad/issues);
- report security problems privately, through the repository's **Security → Report a vulnerability** page, not in public issues.

Changes to the document format, the validator or the viewer belong in the [flexova](https://github.com/EagleMind/flexova) repository (Apache-2.0), which has its own contribution rules.
